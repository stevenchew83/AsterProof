# Concept alias resolution

`inspinia/pages/data/concept_alias_policy_v1.json` refines the four subject catalogs without rewriting stored tags, concept IDs, assessment profiles or completion identities.

Resolution is EXACT, CONTEXTUAL or AMBIGUOUS. ACTIVE and DEPRECATED describe lifecycle independently. INCORRECT is recorded as a finding about an old binding. The current policy introduces no deprecated captions; future deprecated assignments require an explicit approved replacement and retain their original provenance.

The first priority batch corrects generic substitution, linear recurrence, finite differences and telescoping. Expansion and rank require the reviewed same-source mathematical context. Matrix method remains ambiguous. The short sum-of-two-squares lemma requires explicit Fermat theorem evidence; representation remains a separate identity. Explicit Matrix rank captions resolve exactly.

Context is scoped to the source tag's subject, caption, family and required co-tags. A neighboring source cannot supply evidence. Statement tags take precedence over linked-problem tags, including suppressed statement tags. The statement topic precedes its linked problem topic when a source has no declared subject. Missing or contradictory context holds the association.

The alias policy contributes to catalog cache keys. Progress and practice use the same identity rules. Existing independently supported associations remain. This batch does not merge the remaining shared subject identities or calibrate ratings.

Regression coverage is in `test_concept_alias_policy.py` and the subject-catalog suites. No data or schema migration is needed.
